# CepayaBot-MD
Bot de WhatsApp Multi-Device (Baileys) de alto rendimiento, optimizado con un motor de intenciones dinámico por subcarpetas, super-limpieza de argumentos y procesamiento inteligente con IA.
# 1. Inicializa tu repositorio local (si no lo habías hecho antes)
git init

# 2. Vincula tu carpeta local con el GitHub que acabas de crear
# (Copia el enlace de tu repositorio de la barra de navegación)
git remote add origin https://github.com/RoberthCepaya/CepayaBot-MD.git

# 3. Trae el README inicial que creó GitHub para sincronizar ambas partes
git pull origin main --rebase

# 4. Ahora reemplaza TODO el contenido de tu archivo README.md local 
# con el diseño "Multi-Uso 24/7" que te pasé arriba y guárdalo.

# 5. Registra el archivo modificado
git add README.md

# 6. Crea el commit indicando que estás en desarrollo activo
git commit -m "docs: release initial pro readme for active development"

# 7. Asegúrate de estar en la rama correcta
git branch -M main

# 8. ¡Sube tu súper README final a GitHub!
git push -u origin main
